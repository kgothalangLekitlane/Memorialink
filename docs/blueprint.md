# **App Name**: MemoriaLink

## Core Features:

- Memory Creation: Users can create memory posts with text and dates.
- Memory Sharing: Users can share memory posts with friends via a generated link.
- User Authentication: Secure user login and registration.
- AI link analysis: This tool scans a given link and then uses reasoning to decide whether to incorporate information in the content.
- Link Display: Show the original url link in the memory as a separate display, if link analysis results allow.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) for a calm and reflective feel.
- Background color: Light gray (#F0F0F0) to ensure readability and a clean interface.
- Accent color: Warm orange (#FFB347) for important actions like sharing.
- Body font: 'PT Sans', a versatile and modern sans-serif suitable for the bulk of memory descriptions.
- Headline font: 'Playfair', a high contrast, elegant sans-serif, for display of titles
- Simple, minimalist icons for navigation and actions.
- Clean, card-based layout for displaying memories.
